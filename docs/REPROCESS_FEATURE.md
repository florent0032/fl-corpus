# 重新处理功能说明

## 功能概述

新增的"重新处理"功能允许用户将已处理完成的词语从词库中删除，并重新加入待处理队列，以便后续使用不同的配置（供应商、模型、提示词等）重新生成词条。

## 使用场景

1. **对生成结果不满意**：想要使用不同的 LLM 模型或提示词重新生成词条
2. **更新了输出格式**：输出格式修改后，需要重新生成符合新格式的词条
3. **知识库更新**：添加了新的语料后，想要重新检索用例并生成更好的词条
4. **批量修正**：发现某些词条质量不佳，需要批量重新处理

## API 端点

### 1. 单个词语重新处理

**端点**: `POST /api/words/processed/{collection_id}/{word}/reprocess`

**功能**: 将指定词语从词库删除并重新加入待处理队列

**请求体** (可选):
```json
{
  "lang": "ja",                    // 语言代码（可选，会自动推断）
  "json_input": {},                // 词条输入信息（可选，会从已处理词条提取）
  "knowledge_bases": ["kb1"],      // 知识库列表（可选）
  "fallback_words": ["word1"]      // 兜底词列表（可选）
}
```

**响应**:
```json
{
  "success": true,
  "message": "已将 食べる 从词库 n1 删除并重新加入待处理队列",
  "data": {
    "id": "20260613120000123456",
    "lang": "ja",
    "collection_id": "n1",
    "word": "食べる",
    "json_input": {...},
    "status": "pending",
    ...
  }
}
```

### 2. 批量重新处理

**端点**: `POST /api/words/processed/batch-reprocess`

**功能**: 批量将多个词语从词库删除并重新加入待处理队列

**请求体**:
```json
{
  "collection_id": "n1",           // 词库 ID（必填）
  "words": ["食べる", "飲む"],     // 词语列表（必填）
  "lang": "ja",                    // 语言代码（可选）
  "knowledge_bases": ["kb1"],      // 知识库列表（可选）
  "fallback_words_map": {          // 兜底词映射（可选）
    "食べる": ["食べ", "食べた"]
  }
}
```

**响应**:
```json
{
  "success": true,
  "message": "已将 2 个词语从词库 n1 删除并重新加入待处理队列（新增 2，更新 0）",
  "data": {
    "removed": 2,
    "added": 2,
    "updated": 0
  }
}
```

## 前端使用方式

### 方式一：单个词语重新处理

1. 进入 **任务管理** 页面
2. 选择一个已完成的任务查看详情
3. 切换到 **词语列表** 标签页
4. 找到已处理的词语（状态为"成功"）
5. 点击右侧的 **🔄 重新处理** 按钮
6. 确认操作后，词语将被移回待处理队列

### 方式二：批量重新处理

1. 进入 **任务管理** 页面
2. 选择一个已完成的任务查看详情
3. 切换到 **词语列表** 标签页
4. 点击 **全选已处理** 按钮，或手动勾选需要重新处理的词语
5. 点击右上角的 **🔄 重新处理 (N)** 按钮
6. 确认操作后，所有选中的词语将被移回待处理队列

### 方式三：从任务概览进入

1. 进入 **任务管理** 页面
2. 选择一个已完成的任务查看详情
3. 在 **任务概览** 标签页中，点击 **📋 查看 N 个已处理词语** 按钮
4. 系统会自动切换到词语列表并筛选出已处理的词语
5. 按照上述方式选择并重新处理词语

## 处理流程

```
已处理词语（output/{collection_id}.json）
    ↓
用户点击"重新处理"
    ↓
从词库中删除该词条
    ↓
创建新的待处理记录（状态: pending）
    ↓
添加到 pending.json
    ↓
用户可以在"处理词语"页面重新处理
```

## 注意事项

1. **数据备份**: 重新处理会从词库中删除词条，建议先导出备份
2. **重复检测**: 如果待处理队列中已存在相同的词语（相同 word + collection_id），会更新该记录而不是创建新的
3. **语言推断**: 如果不指定语言，系统会根据 collection_id 自动推断
4. **json_input**: 如果不提供 json_input，系统会从已处理词条中提取基本信息（word、pron、pos、meaning_zh）
5. **并发限制**: 同一时间只能运行一个处理任务

## 示例场景

### 场景 1：使用不同的模型重新生成

1. 原任务使用 GPT-4o 生成了词条
2. 想要尝试使用 Claude 重新生成
3. 选择这些词语，点击"重新处理"
4. 在"处理词语"页面选择 Claude 模型，重新处理

### 场景 2：更新提示词后重新生成

1. 发现原提示词生成的词条质量不佳
2. 在"提示词管理"页面优化提示词
3. 选择需要重新生成的词语，点击"重新处理"
4. 在"处理词语"页面选择新的提示词，重新处理

### 场景 3：知识库更新后重新生成

1. 添加了新的语料到知识库
2. 想要让已处理的词语也使用新语料
3. 选择这些词语，点击"重新处理"
4. 在"处理词语"页面重新处理，新语料会被检索使用
